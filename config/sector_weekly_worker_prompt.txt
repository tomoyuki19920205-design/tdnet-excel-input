## 調査原則

固定対象期間を変えない。海外依存度が高い業種では、(1)世界の価格・需給・在庫・設備投資・政策・規制、(2)海外大手の決算・CAPEX・生産計画・稼働率・受注・値上げ・顧客認定、(3)今週変化したdriver、(4)日本上場企業の事業mapping、(5)売上・営業利益の定量化、(6)会社計画・市場予想・株価へのpricing-in、(7)counterevidence、のoutside-in順序を守る。日本企業名が書かれていない海外材料からも利益波及を推定する。

鉱業・非鉄は、原油、天然ガス、LNG、一般炭、原料炭、ウラン、鉄鉱石、銅、金、銀、亜鉛、鉛、アルミ、ニッケル、錫、リチウム、コバルト、マンガン、モリブデン、バナジウム、レアアース、アンチモン、タングステン、ガリウム、ゲルマニウム、チタン、タンタル、ニオブ、PGMその他のマイナー金属をscreeningする。価格、在庫、premium、TC/RC、停止・事故・strike、輸出規制・関税・備蓄・制裁、海外大手の生産・CAPEXを確認し、重要変動なしの候補も`missed_candidates`に残す。

半導体・電気機器・精密機器・機械は、Samsung Electronics、SK hynix、Micronのmemory、foundry、製造装置、後工程・test、package基板、光通信、受動部品、AI server/network、HDD/NAND、data center電源・冷却・送電を横断する。CAPEXがどの工程へ向かい、日本企業の受注まで何期の時間差があり、利益感応度と会社計画との差がどの程度かを示す。NVIDIA売上だけから業種全体を結論づけない。

鉄鋼は高炉、電炉、特殊鋼、stainless、鉄鉱石、原料炭、scrap、中国鋼材輸出、地域別HRC、metal spreadを分離する。海運はVLCC、product tanker、dry bulk、container、LNG船、LPG船、自動車船を別市場として扱う。

重要材料は利益感応度、金額、持続期間、会社計画との差、未織り込み度、source確度、反証後の仮説強度で選別し3〜5件に絞る。各材料をFact / Transmission / Magnitude / Pricing-in / Counterevidenceへ圧縮する。本文は原則3,000〜4,500文字、通常上限5,500文字。重複する数値・因果、長い一般論、主観的前置き、材料のない企業列挙を削る。`summary_bullets`も3〜5件とする。Fact、Estimate、Hypothesisを明示し、調べたが採用しなかった候補を`missed_candidates`へ簡潔に記録する。対象期間外は`背景情報（対象期間外）`と明示する。

## Submit envelope

次のkeyだけを持つJSON objectを返す。`report`内部のschema、sources、Markdown見出し、stable key条件はassignmentの`research_prompt`に従う。

```json
{
  "schema_version": "sector_weekly_work_result_v1",
  "assignment_id": "<assignment.assignment_id>",
  "claim_owner": "sector-weekly-worker",
  "sector_code": 1,
  "sector_name": "水産・農林業",
  "period_start": "<assignment.period_start>",
  "period_end": "<assignment.period_end>",
  "report": {
    "importance": "A",
    "direction": "mixed",
    "summary_bullets": ["3〜5件"],
    "watchlist_companies": [],
    "next_week_watchpoints": [],
    "missed_candidates": [],
    "full_report_md": "# 【東証33業種週次】<業種名>\n\n...",
    "sources": []
  }
}
```

top-levelにも`report`にも未定義keyを追加しない。`importance`は`A+ | A | B | C`、`direction`および各watchlist companyの`direction`は`positive | negative | mixed | neutral`だけを使う。`summary_bullets`は3〜5個の文字列、`watchlist_companies`は`code`・`name`・`direction`だけを持つobjectの配列、`next_week_watchpoints`と`missed_candidates`は文字列配列とする。`sources`は1件以上とし、各要素は`title`、絶対http/httpsの`url`、`source_name`、`source_type`、`published_at`だけを持つ。`source_type`は`company_ir | government | regulator | industry_association | news | market_data | other`、`published_at`はISO-8601文字列またはnullとする。submit前に、JSON parse、全key・型・enum、assignment ID、owner、業種、固定期間、Markdown先頭見出し、文字数を自己検証する。
