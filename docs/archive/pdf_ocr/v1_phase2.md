PDF OCRアップグレード仕様（PHASE2）

目的
OCRテキストを用いてセグメントおよび受注情報を救済的に抽出する。

==================================================
1. 追加ファイル
==================================================
- src/pdf/ocr/layout_reconstruct.py
- src/pdf/ocr/segment_extractor_ocr.py
- src/pdf/ocr/order_extractor_ocr.py
- src/pdf/ocr/text_normalize.py

==================================================
2. 入力データ
==================================================
Phase1のOCR結果を使用

- text（全文）
- 行単位分割済み文字列（最低限splitlines）
- 可能ならbbox情報（任意）

==================================================
3. セグメント抽出
==================================================

アンカー検出
以下を含む行を検出

- セグメント
- セグメント別
- 報告セグメント
- 事業別
- 売上高
- 営業利益
- セグメント利益

抽出範囲
- アンカー行の前後20行

行フィルタ
- 数字を含む行を優先
- 長文（>100文字）は除外

セグメント名
- 行の先頭テキストを候補とする
- 除外: 合計 / 調整 / 全社 / 消去

数値抽出
- 売上高系
- 営業利益系

成功条件
- セグメント2件以上
- 売上高2件以上
- 利益1件以上

==================================================
4. 受注抽出
==================================================

アンカー
- 受注
- 受注高
- 受注残
- 受注残高
- backlog

範囲
- アンカー前後10行

抽出対象
- 金額のみ
- 単位（百万円 / 億円）も取得

成功条件
- 受注または受注残1件以上

==================================================
5. 正規化
==================================================

- 全角→半角
- カンマ除去
- △/▲を負数へ変換
- 単位換算（億円→百万円）

==================================================
6. 統合（重要）
==================================================

src/extractor.py に追加

流れ

1. native抽出実行
2. OCR fallback実行（Phase1）
3. financials抽出
4. セグメント抽出（OCR）
5. 受注抽出（OCR）
6. 結果を補完

ルール

- native成功値は上書きしない
- OCRは補助のみ
- validatorは変更しない

==================================================
7. ログ
==================================================

- [segment-ocr] anchor found
- [segment-ocr] segments extracted count=...
- [order-ocr] anchor found
- [order-ocr] value extracted
- [ocr] no improvement

==================================================
8. 完了条件
==================================================

- セグメント抽出成功率が改善
- 受注抽出成功率が改善
- 誤抽出増加なし
- native影響なし
