PDF OCRアップグレード仕様（PHASE2 SUMMARY）

目的
OCRで取得したテキストを使い、セグメント情報および受注情報の抽出精度を改善する。

前提
- Phase1でOCR fallbackは導入済み
- OCRテキストは取得可能
- 現在はfinancials（売上/営業利益）のみ救済

今回やること
- OCRテキストからセグメント情報を抽出
- OCRテキストから受注・受注残情報を抽出
- アンカー（キーワード）ベースの限定解析
- native抽出失敗時のみ救済

やらない
- 全文構造解析
- LLM解析
- 完全な表復元
- DBスキーマ変更

基本方針
- OCR結果は補助扱い
- native成功時は使用しない
- アンカー周辺のみ解析（高速・安全）
- validator基準は変更しない

アーキテクチャ
1. OCRテキスト取得（Phase1）
2. セグメントアンカー検出
3. 周辺行から数値抽出
4. 受注アンカー検出
5. 周辺行から数値抽出
6. 既存結果へ補完

成功条件
- セグメント2件以上取得できるケースが増える
- 受注/受注残が取得できるケースが増える
- 誤検出が増えない
- native結果は不変

実装優先順位
1. セグメント抽出
2. 受注抽出
3. ログ/可視化

指示
- 実装計画を作成
- 差し込み箇所を特定
- まだ実装しない
- 簡潔に回答
