# EPS縦ブロック抽出 改善仕様

## 目的
forecast_revision における EPS 抽出精度を上げる。

現状は EPS を主テーブルの一部として取るロジックが中心であり、
「1株当たり当期純利益」ラベルの真下に前回EPS、その下に修正後EPSが並ぶ
縦ブロック形式の開示を取りこぼしやすい。

そのため、EPSラベル位置を起点に
「真下1行・真下2行を優先して読む」縦ブロック抽出を追加する。

---

## ゴール
以下のようなパターンで EPS を取得できるようにする。

### パターンA: 数値だけ縦並び
1株当たり当期純利益
100.50
150.30

→ previous_eps = 100.50
→ revised_eps = 150.30

### パターンB: ラベル付き縦並び
1株当たり当期純利益
前回発表予想 100.50
今回修正予想 150.30

→ previous_eps = 100.50
→ revised_eps = 150.30

### パターンC: 円銭ヘッダ付き
（円銭）
1株当たり当期純利益
100.50
150.30

→ previous_eps = 100.50
→ revised_eps = 150.30

## 実装方針

### 1. EPSラベル検出後の縦ブロック優先読みを追加
既存の _find_eps_from_lines() を拡張、または
専用ヘルパーを追加する。

候補関数名:
- _find_eps_vertical_block()
- _extract_eps_below_label()

処理順序:
1. EPSラベル行を見つける
2. その直下1〜3行を優先して調べる
3. 数値行が2本見つかれば
   - 1本目 = previous_eps
   - 2本目 = revised_eps
   とみなす
4. 「前回」「今回修正」等の語がある場合は、それを優先して対応付ける
5. 縦ブロックで取れなければ、既存の周辺探索ロジックにフォールバック

重要:
- 既存の主テーブル抽出は壊さない
- まず縦ブロック優先、その後に既存 fallback でもよい
- もしくは既存 fallback の最初に縦ブロックを追加してもよい

---

### 2. EPSラベル候補
以下をラベル候補として使うこと。

- 1株当たり当期純利益
- １株当たり当期純利益
- 一株当たり当期純利益
- 1株当たり四半期純利益
- １株当たり四半期純利益
- 一株当たり四半期純利益
- 1株当たり純利益
- １株当たり純利益
- 一株当たり純利益
- 1株当たり当期純損益
- １株当たり当期純損益
- EPS
- eps

---

### 3. OCR正規化の前提
OCR正規化で以下が結合されている前提を維持する。

- 1 株 当 た り → 1株当たり
- 一 株 当 た り → 一株当たり
- E P S → EPS
- 円 銭 → 円銭
- 当 期 純 利 益 → 当期純利益

必要なら追加してよい。

---

### 4. 縦ブロック抽出ルール

#### 基本ルール
EPSラベル行の次の行から最大3行程度を見る。

候補行の条件:
- 数値を1個以上含む
- 注記だけの行ではない
- 他のメトリクス名（売上高、営業利益等）を含まない

#### 優先順位
1. 「前回」「前回予想」「前回発表予想」などを含む行
2. 「今回」「今回修正」「修正後」「今回予想」などを含む行
3. 純粋な数値行2本

#### 数値の扱い
- 最初の主要数値を採用
- 負号（△, ▲, -）を許容
- 小数を許容
- 円銭表記に対応
- % は除外

#### fallback
縦ブロックで取れなかった場合は既存ロジックを使う。

---

### 5. 誤検出防止
以下のケースは縦ブロックとして採用しないこと。

- 直下行が売上高、営業利益など別メトリクス
- 直下行が注記や文章
- 数値が日付やページ番号らしい
- 1本しか数値行がなく、前回/今回ラベルもない場合は片側のみ採用してよいが、ログで分かるようにする

---

### 6. ログ追加
INFO または DEBUG で以下を出す。

- [forecast_ocr] eps_label_detected line=...
- [forecast_ocr] eps_vertical_candidate lines=...
- [forecast_ocr] eps_vertical_result prev=... rev=...
- [forecast_ocr] EPS prev=... rev=...

最低でも最終結果は出すこと。

## テスト要件

### 新規テスト
1. 数値だけ縦並び
- ラベル直下に 100.5 / 150.3 が並ぶ
- prev=100.5, rev=150.3

2. 前回/今回ラベル付き
- 前回発表予想 100.5
- 今回修正予想 150.3
- prev/rev 正しく対応

3. 円銭ヘッダ付き
- （円銭）配下でも抽出

4. OCR分断ラベル
- 1 株 当 た り 当 期 純 利 益
- E P S
- 正規化後に抽出可能

5. 負のEPS
- 31.23 → -62.04
- rev が負値で取得できる

6. 片側のみ
- prev=12.0, rev=None
- または prev=None, rev=16000.0
- 片側取得が壊れない

7. 誤検出防止
- 売上高や営業利益の行をEPSとして誤認しない

## 期待効果
現状:
- EPS痕跡取得率は一定ある
- ただし A円→B円 の両取り率が低い

改善後:
- 「1株当たり当期純利益」直下の縦ブロックから両取りできる案件が増える
- EPS通知表示率が上がる
- OCR案件でもEPSの両取り率が改善する
