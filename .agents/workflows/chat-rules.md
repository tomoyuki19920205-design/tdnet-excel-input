# チャット運用ルール（コンテキスト肥大化防止）

## 1. 1チャット1目的
- チャット開始時に「今回は〇〇だけを行う」と目的を明確にする
- 目的が完了したらチャットを終了し、次の作業は新しいチャットで行う

## 2. ファイル読み書きの最小化
- 巨大ファイルは全文読まず、必要箇所だけ参照する（StartLine/EndLine指定）
- 同じファイルの繰り返し読みを避ける

## 3. 出力の最小化
- テスト実行は `-q --tb=short` をデフォルトにする
- テストログは要約中心、失敗時のみ詳細を出す
- コマンド出力が長い場合は要約する

## 4. 進捗報告フォーマット
毎回の報告は以下の3点のみ：
1. **変更ファイル**: 今回変更したファイル一覧
2. **未完了タスク**: 残りのタスク
3. **次コマンド**: 次に実行する内容
